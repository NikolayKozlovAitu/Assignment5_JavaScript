## Description
This project is completed as part of the Web Technologies course at Astana IT University. It covers core JavaScript concepts including syntax basics, DOM manipulation, event handling, and an interactive To-Do application.

## Structure
- **Part 1 (index.html):** First script, console logging, alert, and basic variables/operators.
- **Part 2 (pages/dom.html):** Changing HTML content, modifying element styles dynamically, and adding/removing list items.
- **Part 3 (pages/events.html):** Mouse events (mouseover/mouseout), keyboard real-time input tracking (keyup), and a basic calculator.
- **Part 4 (pages/todo.html):** Interactive To-Do List application supporting task creation, completion toggling, and deletion.
